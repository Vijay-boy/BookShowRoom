# 📚 BookShowRoom Management System

## 📌 Project Description
BookShowRoom is a Full Stack Web Application developed to manage books efficiently. Users can add, update, delete, and view book details.

## 🚀 Technologies Used
### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Java
- Spring Boot

### Database
- MySQL

## ✨ Features
- Add Book
- Update Book
- Delete Book
- View Books
- Responsive User Interface
